# SUNLINK OS

Page de connexion de SUNLINK OS (Groupe SUNLINK).

Ce dépôt ne contient que la page publique de connexion. L'application et toutes ses données sont stockées
dans un espace sécurisé (Supabase), accessible uniquement après connexion aux personnes autorisées.

`env.js` contient l'adresse du projet et sa clé publique (anon), publiques par conception : la sécurité est
assurée par les règles d'accès côté base de données.
